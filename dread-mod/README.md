# Dread — a horror mod for Minecraft 1.20.1 (Fabric)

Needs: Fabric Loader 0.15+, Fabric API, Java 17.

## Build it with GitHub (no installs)
1. Create a new GitHub repo and upload everything in this folder (keep the `.github/workflows/build.yml` path exactly).
2. Open the **Actions** tab → the "Build Dread mod" run starts automatically (or press *Run workflow*).
3. When it turns green, open the run and download the **dread-mod** artifact. Unzip it: the `dread-1.0.0.jar` goes in your `mods` folder.
4. If the run is red, open it, copy the error from the Build step and send it to me.

## Creatures
| Name | Behaviour |
|---|---|
| **Stalker** | Hunts you through walls. Freezes solid while you look at it, blinks closer when nobody's watching. Hits cause Darkness. |
| **Crawler** | Fast wall-climbing spider that pounces and cripples with Slowness. |
| **Watcher** | Tall faceless figure that only stares. Get within 10 blocks, stare back for 5s or hit it and it jumpscares you, then vanishes. Unkillable. |
| **Wailer** | Ghost that floats through walls, wails (Darkness pulses) and inflicts Wither. |

All have glowing eyes. Textures are generated by `tools/generate_textures.py`, or just replace the PNGs.

## Commands (need cheats / op level 2)
```
/horror spawn <stalker|crawler|watcher|wailer|random> [count]
/horror event <name> [players]
/horror auto <true|false>        random haunting while you play
/horror intensity <1-5>
/horror griefing <true|false>    lightsout may snuff nearby torches
/horror clear                    remove all creatures & cancel events
/horror status
```
### Events
`whispers` `footsteps` (something walks up behind you) `knocking` `creeperhiss` `heartbeat` `message` (creepy chat)
`lightsout` (darkness + torches die) `sighting` (a Watcher appears far away) `ambush` `jumpscare`
`nightmare` (scripted multi-minute sequence) `swarm` (one of everything) `bloodmoon` (night, thunder, endless spawns for 2 min)

## Items
* **Dread Shard** — dropped by creatures.
* **Haunted Bell** — bell + 4 shards (plus shape). Right-click: something random happens. 45s cooldown.
* Spawn eggs for all four creatures.

Settings (auto/intensity/griefing) reset on restart. Enjoy not sleeping.
